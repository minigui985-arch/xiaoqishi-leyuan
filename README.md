# 小骑士乐园

以十字军与明军双阵营文化角色为主题的国际象棋启蒙、学习与实战项目，提供儿童Q版和成人版人物皮肤。

> 当前状态：本地开发与联调阶段。本仓库暂为私有仓库，尚不代表已经达到应用商店正式上线标准或已开放公网服务。

## 当前能力

- 棋盘、棋子和走法启蒙课程；
- 符合国际象棋基础规则的本地对局；
- 儿童探索模式与国际赛事规则方向；
- 引导提示、错误走法建议和军事行军路线复盘；
- 儿童Q版、成人版双皮肤及十字军、明军双阵营；
- 本地好友房间联调、反馈收集和断点恢复基础能力；
- 沉浸棋盘与多尺寸屏幕适配。

云端正式联机、应用商店合规、用户体系、内容审核和正式AI引擎接入仍属于后续工作，详见项目内交付及待办文档。

## 本地运行

直接使用现代浏览器打开：

`小骑士乐园-统一主题版.html`

好友联调服务和反馈服务的具体限制，请阅读对应说明文档。运行产生的房间、反馈及用户数据不应提交到仓库。
